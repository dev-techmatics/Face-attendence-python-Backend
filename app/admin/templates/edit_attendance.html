Only the direction and the time can be changed. The result is fixed on purpose: turning a refusal into an acceptance would record an attendance no camera ever saw, which is the one thing this service exists to prevent. If a refused attempt really was that person, add a punch instead and say so here — that leaves both the refusal and the correction on the record.

Every change is kept, with the old value, the new value, the reason and the moment it was made. The record says it was an admin, not which one: the dashboard has one shared admin login, so that is as far as it can honestly go.
